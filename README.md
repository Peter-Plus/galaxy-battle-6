## 项目概述

galaxy-battle-6 是一个基于 Web 的太空射击类游戏，侧重于轻量、即开即玩和易于二次开发。项目主要使用原生 JavaScript 与 CSS/HTML 实现，可直接在现代浏览器中运行，适合部署在静态网站或接入常见前端打包工具链。

适用场景：
- 作为前端小游戏的学习/示例项目
- 练习游戏循环、碰撞检测、资源管理与本地存储
- 快速自定义皮肤或玩法，嵌入个人网站/作品集中

## 安装与启动

你可以选择【静态站点方式】或【Node.js 工具链方式】运行项目。

### 方式 A：静态站点/本地服务器

1) 克隆项目
```bash
git clone https://github.com/Peter-Plus/galaxy-battle-6.git
cd galaxy-battle-6
```

2) 直接打开或使用本地服务器
- 直接双击/拖拽 `index.html` 到浏览器中打开（简单资源引用通常可用）
- 推荐使用本地静态服务器（可避免 CORS 问题），任选其一：
```bash
# 选项 1：Node 环境
npx serve .

# 选项 2：Python 3
python -m http.server 5173

# 选项 3：Bun
bunx serve .
```
然后在浏览器访问命令行输出的地址（例如 http://localhost:5173）。

### 方式 B：Node.js 工具链（如存在 package.json）

若仓库包含 `package.json`，可按以下步骤启动开发服务器和构建产物。若仓库为纯静态文件，可忽略本节。

```bash
# 1) 安装依赖（任选其一）
npm install
# 或
yarn
# 或
pnpm install

# 2) 启动开发服务器（脚本名称以实际 package.json 为准）
npm run dev

# 3) 生产构建
npm run build

# 4) 预览构建产物
npm run preview
```

## 使用说明（玩法）

- 启动游戏：按上述方式打开/运行后，进入主页点击"Start"或"Play"。
- 基本操作（示例，若与实际不符请以游戏内设置/说明为准）：
  - 移动：W/A/S/D 或 方向键
  - 射击：空格键 或 J/K
  - 超级技能/炸弹：Shift 或 L
  - 暂停：P 或 Esc
  - 触屏：屏幕左侧拖动移动，右侧点击/长按射击
- 目标：尽可能击败更多敌人、躲避弹幕与碰撞；击败 Boss 获得更高分。
- 提示：
  - 观察敌机弹道与移动规律，合理走位。
  - 收集道具，优先保障生存（护盾/回血）。
  - 难度过高时可在设置面板降低难度或将画质调为"低"。

## 常见问题 FAQ

- Q：打开 `index.html` 没有声音/资源报错？
  - A：部分浏览器需要用户交互后才能播放音频；资源跨域时，请使用本地静态服务器而非直接用 file:// 打开。

- Q：帧率不稳定或卡顿？
  - A：在设置中将画质调低，或关闭部分特效；建议使用性能更好的浏览器，并关闭后台占用较高的标签页。

- Q：按键不生效？
  - A：确保游戏画面已获得焦点（点击画布区域）；检查键位映射配置；在 macOS 上可能需要将某些系统级快捷键改用其他组合。

- Q：如何部署到静态托管（GitHub Pages、Vercel 等）？
  - A：若为纯静态站点，直接将根目录或 `dist/`（构建产物）部署即可。GitHub Pages 可在 Settings → Pages 中选择分支与路径。
